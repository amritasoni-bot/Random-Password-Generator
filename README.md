# Random-Password-Generator 


This is a beginner-friendly Python application that i made before my college begins.
In this application , user will get random suggested password with customizable length and can also choose characters , numbers and symbols that  should be in their password.

## What i learned
1- User data handling
2- Loops
3- String Manipulation
4- Conditional statements
5- Python's Random module 

This project is part of my journey through which i came to know that how real password generator works while strengthing my programming fundamentals.
